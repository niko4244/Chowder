# P11 rung 4 — draft (2026-09-15)

**Status: DRAFT, not a preregistration.** The rung-4 prereg will be built from
`docs/quals/PREREG_TEMPLATE.md` (its first user), committed before any
implementation, and judged mechanically per `docs/quals/HARNESS.md`. Numbers
below are proposals derived from measured rung-3c artifacts; they bind only
when the prereg lands.

## What rung 3c unlocked (evidence-backed)

1. **An honest paired budget model.** Device truth 0.0167 GPU-h measured;
   wall multiplier **M = 3.5** (0.0585 wall / 0.0167 device) with the
   double-charge defect fixed — a paired baseline row now records
   `gpu_hours 0.0` and discloses `shared_wall_gpu_hours` / `charged_to`.
   The next prereg can predict its wall charge before the run instead of
   exceeding an asserted envelope after it.
2. **An explicit collapse contract (T4a).** Rungs 3b/3c proved the base
   routers arrive maximally collapsed (all 32 layers → expert 0, 480/512
   dead experts) and training de-collapsed 29 layers (→ 428 dead experts)
   while 3 stayed fully saturated (exact-zero grads, honestly recorded).
   Quality judgment no longer rides a binary that such topology overstates.
3. **The full device path on a real accelerator**: load → train (12 steps,
   1536 tokens/step) → freeze → publish → paired evaluate → account, all
   under enforced, measured, decomposed budgets, with the harness/template
   making every future verdict mechanical.

## Rung 4: longer-horizon paired CUDA qualification

**Goal:** move from *trainability* (rung 3c) to *preregistered routing
effectiveness* on the same 9B-derived artifact — the first run judged on
whether training de-collapses routing further, not merely that it updates.

**Workload proposal** (frozen at prereg time):

- Paired arms (single resident eval pair), `bf16-offload-transient`, RTX 5060 Ti.
- Horizon 48 steps × 1536 tokens (4× rung 3c's 12; load share drops from
  ~23% to ~8% of device time — amortization the paired path bought).
- **Independent holdout shard**: eval corpus distinct from the training
  shard, byte-pinned separately (rung 3c scored the training protocol;
  rung 4 adds a real generalization read).

**Budget proposal** (derived per the template's rule, from rung-3c probes):

- Step basis: 3.034 s/step measured (rung-3c attempt-3 probe) × 48 = 145.6 s;
  plus one load (13.9 s measured) = 159.5 s device ≈ 0.0443 GPU-h;
  ×1.5 margin ⇒ **device ceiling 0.066 GPU-h** with the same decomposed
  sub-budgets (loads / steps / generations).
- Wall envelope: 0.066 × **M = 3.5** ⇒ **0.23 wall GPU-h** (predicted, not
  asserted; candidate row only under the post-fix ledger).

**Threshold deltas vs rung 3c:**

- T4a tightened: `dead_experts_after < 428` (strict de-collapse progress),
  grad-zero allowance ≤ 2 of 32 layers, any fully-dead layer explained with
  base-routing evidence (topology vs optimizer).
- New quality threshold (T9): base-vs-candidate loss delta on the independent
  holdout must exceed a preregistered margin (value set at prereg from a
  baseline re-measure; the threshold is the delta on the *holdout*, not the
  training protocol).
- T5: 48/48 steps, `stop_reason=max_steps`; T6 paired contract unchanged;
  T7 accounting on the device basis with the predicted envelope recorded.

## What stays gated before the 9B-successor pilot (rung 5)

1. **The arithmetic gate is architectural, not operational.** The 9B-derived
   backbone's non-FFN floor is **4.122B parameters** (measured from tensor
   headers, full non-routed text convention). FFN-only routing can never
   reach **≤3.5B active** on it. The successor pilot requires the separately
   gated architecture task: a budget-valid narrower/different always-on
   backbone. Rung 4 does not and cannot bypass this.
2. **Quality, not just routing.** De-collapse and a holdout delta are still
   proxy signals; a usable checkpoint needs a downstream task read
   (tiny probe set first) preregistered before any promotion claim.
3. **Horizon realism.** 48 steps is still a mechanical control. The pilot's
   step count and corpus must be sized from the measured per-step cost with
   the ×1.5 discipline, and the collapse allowance re-derived from rung-4
   evidence (saturated-softmax behavior at longer horizons is unknown).
4. **Cost truth at scale.** Every scale-up inherits the M-multiplier
   accounting: wall envelopes must be predicted from measured device budgets
   on the same run class, never asserted.
