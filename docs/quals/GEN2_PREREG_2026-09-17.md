## 1. Target, chosen from fresh measurement (not assumption)

Gen1's instrument evidence (16 prompts, `candidate_evaluation.json`) was
re-measured here, per prompt:

| Observed defect | Measured rate on gen1 | Status |
|---|---|---|
| Post-think answer duplication (answer stated in the reasoning block, then repeated verbatim after `</think>`) | **0.688** (11/16) | TARGET |
| Template/prompt echo (continuation begins with the prompt tail + literal `assistant` before `<think>`) | **0.438** (7/16) | TARGET |
| Format/length non-compliance on a constrained prompt ("How many continents are there?" → enumerated list) | 1/16 | TARGET (secondary) |
| Termination / cap-hit / unclosed-think / obvious loops | 1.000 / 0.000 / 0.000 / 0 | REPAIR HOLD: must not regress |
| Answer-correct (expected string present after reasoning) | 16/16 | HOLD: must not regress |

**Gen2 target = response-surface compliance**: the answer is emitted exactly
once, in the answering surface; the continuation never echoes the prompt
template; constrained prompts are obeyed. This is genuinely trainable with
SFT-style data and needs no new benchmark — the same 16-prompt diagnostics
instrument measures all three, at the cost already measured.

Why not "non-termination" (the previously recommended target): it is already
repaired (1.000) and re-targeting a fixed defect would waste a cycle. The
recommendation was checked against evidence and rejected by it.

Statistical rule: a target gate is met only when the paired per-prompt

deltas) **or** the frozen absolute threshold is crossed with a strictly
lower rate on ≥ 12/16 prompts. A tie fails.

## 5. Budgets (explicit units; settled, not merely admitted)

| Unit | Per recipe | Campaign |
|---|---|---|
| device GPU-h | 0.30 | 0.60 |
| wall GPU-h | 0.75 | 1.50 |

- Admission: each recipe's *projection* must fit the per-recipe ceilings
  before any attempt starts.
- Settlement: each attempt's and the campaign's *actual* measured cost must
  fit these ceilings after execution, or the cycle refuses
  (`ACTUAL_*_EXCEEDED` / `RESOURCE_OVERRUN`) with artifact preserved.
- Baseline: the parent's instrument + slice measurement is referenced at zero
  incremental cost (`baseline.mode: fixed`), never re-paid per recipe.
- Probe: before the real run, one bounded step-probe measures the actual
  per-step cost; the horizon is set from that measurement in a written
  amendment, never enlarged after results.

## 6. Execution contract

1. Campaign manifest `docs/gen2/gen2_campaign.json` validated
   (`chowder growth campaign validate`).
2. Parent freeze: adapter digest verified, slice measurement taken once.
3. Both recipes trained through the production `SubprocessTrainingFn`; every
   attempt immutable (`attempt-NN`), failures preserved.
4. Candidate selected by `first_successful` from training-side evidence only
   (protected scores are structurally unreachable to selection).
5. Candidate measured on the 16-prompt instrument **and both mini-slices**;
   all rows carry `measurement_origin=MEASURED_THIS_GENERATION`, parent rows
   `MEASURED_PARENT`, historical rows `CARRIED_REFERENCE`, unrun benchmarks
   `UNMEASURED` (honest absence, never zero).
6. `chowder growth campaign settle` over the cycle accounting artifact.
7. Mechanical judge: `docs/gen2/judge_gen2.py` (frozen with this prereg).

## 7. Verdicts and branch rules

| Outcome | Meaning |
|---|---|
| All gates pass | PROMOTED: gen2 becomes the current generation; line continues |
| Target met, protected incomplete | INCONCLUSIVE with `target_repair_validated=true`; candidate remains live, no promotion |
| Target not met | REJECTED; gen1 remains the current branch point; negative result recorded durably |
| Any protected regression / contamination / settlement breach | REJECTED (hard), artifact preserved as evidence |

A rejection is an acceptable, informative outcome. Thresholds are not to be
weakened to obtain a first promotion.

## 8. What this cycle does NOT claim

It does not claim general capability gain (the mini-slices are small,
low-power measurements), frontier parity (frontier scores never decide
promotion), or that the gen1 promotion question is settled — a full protected
evaluation of gen1 remains the prerequisite for promoting *gen1*.
