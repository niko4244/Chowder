## Governing immutable rules and conflict

- `docs/REAP_QWEN36_PREREG.md` §4, lines 55–78: paired binary correctness `d=x(arm)-x(dense)`, one-sided 95% **sample-SD Wald** lower bound `mean(d)-1.645*sd_sample(d)/sqrt(n)`. D0 requires 40 observed layers and perplexity strictly below 20. Gate 0: GSM8K 1,319 termination no worse than dense by 0.02, degenerate distinct-trigram rate (<0.5) no worse by 0.02. Gate 1: GSM8K lower bound strictly above **−0.03**. Gate 2: HumanEval 164 lower bound strictly above **−0.10**. Negative control: `LB(REAP−random128)>0`. Those conditions are not interchangeable with the later optional comparator.
- Original §4 speed/fit: mean llama-server `predicted_per_second` ≥1.3× dense, same flags; REAP128 fully GPU offloaded (zero expert CPU offload), VRAM measured with other residents. Amendment 2/3 fixes **Q8_0 for quality** and independently **BF16→Q4_K_M for placement and speed**. `chowder_batch/reap_gates.py` lines 148–158 enforces identical first 200 GSM8K item IDs (`gsm8k-0` through `gsm8k-199`) and all 200 valid speed readings for the new speed session; never score quality from Q4.
- Original §5 and Amendment 4 §3, lines 182–188: if REAP128 v1 fails Gate 0 or 1, both REAP128_v2 and REAP160 must be scored, then apply the ordered fallback REAP128_v2 → REAP160 → REAP160_v2 (last only if prior two fail). REAP160 permits partial offload if ≥1.3× dense. The *optional replacement of passing v1* is a different branch.
- Amendment 4 §1–2, `docs/REAP_QWEN36_PREREG.md` lines 171–181: optional replacement requires all v2-vs-dense gates, plus **both** same-item GSM8K 1,319 and HumanEval 164 `LB(v2−v1)>−0.02`, labeled **“paired McNemar, one-sided 95%.”** The amendment expressly acknowledges access to original v1 raw Q8 summaries when written (lines 156–163). It does not specify a mathematical marginal-risk-difference McNemar CI construction at null margin −0.02. Standard conditional McNemar equality testing at null difference zero alone cannot yield that CI. The §4 Wald interval is fully specified but cannot silently be substituted for the differently named amendment test.

The detailed, pre-existing independent methods review `docs/quals/reap-v2-paired-ci-prospective-method-review-20261025.md` lines 7–99 already identifies this ambiguity and gives synthetic counterexamples (HumanEval b=0,c=1 and GSM8K b=0,c=19) where section-4 Wald alone appears favorable but an illustrative nuisance-constrained score test does not. These are mathematical **counterexamples, not original-model outcomes or an approved alternative score method**. `chowder_batch/reap_select.py` lines 40–51 and 99–114 already explicitly block optional replacement for this discrepancy.
